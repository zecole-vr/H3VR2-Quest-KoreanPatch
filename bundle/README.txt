H3VR2 Quest 한국어 패치 0.5.2
제작자 · 제콜 (ZECOLE) | https://www.youtube.com/@zecole
저장소: https://github.com/zecole-vr/H3VR2-Quest-KoreanPatch
문의: https://github.com/zecole-vr/H3VR2-Quest-KoreanPatch/issues/new/choose

지원: Meta Quest 단독판 20261119E / versionCode 200534, Quest 3 / Quest 3S (실기 검증은 Quest 3).
정확한 원본 APK와 데이터 체크섬까지 일치해야 설치합니다.
다른 게임 버전, Steam/PCVR, Android 휴대폰 설치는 지원하지 않습니다.

설치
1. 정품 게임을 Quest에 설치하고 한 번 실행한 뒤 완전히 종료합니다.
2. Quest 개발자 모드를 켜고 Windows PC에 USB로 연결합니다.
3. 헤드셋에서 USB 디버깅을 허용합니다.
4. H3VR2_Quest_Setup_v0.5.2.exe를 실행해 ‘한글패치 설치’를 누릅니다.
   ADB가 없으면 최초 한 번 Google 약관 동의 후 공식 연결 도구를 준비합니다.
5. ‘설치 완료’를 확인한 다음 게임을 실행합니다. 작업 중 USB를 분리하지 마세요.

제거·복구
게임을 종료하고 같은 EXE의 ‘제거 · 원본 복구’를 누릅니다.
원본 APK를 수정·재서명·재설치하지 않으며, 세이브 파일을 변경하거나 초기화하지 않습니다.
지원 버전 밖으로 게임이 업데이트되었거나 알 수 없는 파일이 있으면 덮어쓰지 않습니다.
USB 분리나 프로세스 종료 후 다시 실행하면 기록과 해시를 검사하여 복구하고, 그 작업이 Quest에 남긴 임시 파일도 정리합니다.
불명확한 상태에서는 자동 삭제하지 않으므로 백업과 로그를 보존하여 문의해 주세요.
이 EXE를 옮기거나 다시 받아도 아래 지속 저장소의 백업·로그는 유지됩니다.
PC: %LOCALAPPDATA%\ZECOLE\H3VR2\Quest\<기기ID>\200534
기기: /sdcard/Android/obb/com.rustltd.h3vr2/footlong.base.hdog.zecole-original-200534
원본 백업은 제거 후에도 복구 안전성을 위해 보존합니다.

게임 업데이트 후
게임이 20261119E로 업데이트되면 게임 데이터가 새 원본으로 바뀌어 이전 한글패치(0.5.0 이하)가 사라집니다.
이 EXE의 ‘한글패치 설치’로 다시 설치하면 됩니다. 0.5.0 이하 EXE는 새 게임 버전에 설치하지 않습니다.

필수 환경
Windows 10/11 64비트, Microsoft Edge WebView2 Runtime, .NET Framework 4.8.
Python과 bsdiff4 등 패치 실행에 필요한 모듈은 EXE에 포함합니다. 개발 도구 별도 설치 불필요.
ADB 37.0.0은 필요한 경우 공식 서버에서 최초 다운로드합니다.
첫 ADB 준비와 GitHub 최신 버전 확인에 인터넷이 필요합니다.
캐시된 연결 도구와 이 EXE의 패치 데이터로 오프라인 설치는 가능하나 최신 버전 확인은 실패로 표시합니다.
권장 여유 공간: PC 작업 드라이브 7 GiB + 임시 드라이브 0.5 GiB, Quest 3 GiB.
최대 동시 원본/패치/임시 파일과 여유분을 계산하여 설치 전에 다시 확인합니다.

번역 범위·제한
설정·메뉴·작업 안내·여러 게임 내 표지/포스터와 ATM/경보 UI를 번역했습니다.
Challenges/Sandboxes LED 전광판과 일부 오류 코드는 원문을 유지합니다.
초기 시스템 안내 자막 5종과 포어미트 두 질문의 상황 요약을 포함합니다.
0.2.0: 게임 시작 직후 포어미트 구출 장면 대사 2개와 허브 상층 상황 보고 대사 1개의 자막을 추가했습니다.
이 자막은 장면 진입·조작 시점에 맞춘 시간 표시이며 실제 음성 재생을 추적하지 않습니다.
포어미트는 원래 랜덤 음성을 유지하며 요약은 음성 재생 성공·시작·종료를 감지하지 않습니다.
전체 NPC 음성 자막, 인사·작별 요약은 제공하지 않습니다.
전체 게임 문구의 100% 번역이나 모든 진행 경로 검증을 보장하지 않습니다.

검증 상태
파일 재생성 SHA256과 자동 시험 30개 통과. 실제 Quest에서 런처 작업 경로로
시험본 업데이트·동일 버전 확인·원본 복구·원본에서 재설치 완료. APK와 세이브 21개 해시 유지.
게임 화면별 사용자 확인과 공개 다운로드 검증은 최신 검증 기록을 참조하세요.
Windows 마우스 자동 클릭 시험은 화면 캡처 오류로 미실행이며, 런처의 동일 작업 API로 실기 시험했습니다.
상세 최신 검증 상태는 저장소 maintenance/VALIDATION.md와 릴리스 설명을 참조하세요.
