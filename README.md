# H3VR2 Quest 한국어 패치

Hot Dogs, Horseshoes & Hand Grenades 2(Meta Quest 단독판)의 비공식 한국어 패치입니다.

원본 APK는 그대로 두고 외부 게임 데이터에만 차분을 적용합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 최신 버전 | **0.5.6** · [검증 기록](maintenance/VALIDATION.md) |
| 지원 게임 | Meta Quest 단독판 20261124C / versionCode 200542 |
| 지원 기기 | Quest 3, Quest 3S (실기 검증은 Quest 3) |
| 설치 도구 | [ZECOLE VR 런처](https://github.com/zecole-vr/zecole-launcher) (Windows 10/11 x64, WebView2, .NET Framework 4.8) |
| 필요 여유 공간 | PC 작업 드라이브 7 GiB + 임시 드라이브 0.5 GiB / Quest 3 GiB |
| 제작 | 제콜 (ZECOLE) · [YouTube](https://www.youtube.com/@zecole) |

- APK·게임 데이터의 SHA256을 검사하며, 다른 버전에는 설치하지 않습니다.
- Quest 3S는 Quest 3과 같은 게임 파일을 쓰므로 설치를 허용합니다.
- Steam/PCVR, 휴대폰 단독 설치는 지원하지 않습니다.

## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 설치·업데이트·원본 복구를 모두 런처에서 합니다.

1. 정품 게임을 설치하고 한 번 실행한 뒤 완전히 종료합니다.
2. Quest 개발자 모드를 켜고 PC와 USB로 연결합니다. 헤드셋에서 USB 디버깅을 허용합니다.
3. 런처를 실행하고 왼쪽 목록에서 **H3VR2**를 고릅니다.
4. **한글패치 설치**를 누릅니다.
5. **설치 완료** 후 게임을 실행합니다.

### 알아 둘 점

- ADB가 없으면 최초 한 번 약관 동의 후 Google 공식 Platform Tools를 받아 체크섬을 검증합니다.
- 처음 한 번 USB로 연결한 뒤에는 런처에서 무선으로 연결해 설치할 수도 있습니다.
- 새 한글패치 버전이 나오면 런처가 **업데이트 있음**으로 알려 주며, 같은 화면에서 설치하면 됩니다.

## 제거·복구

1. 게임을 종료합니다.
2. 런처의 H3VR2 화면에서 **원본 복구**를 누릅니다.

### 안전 장치

- APK 재서명·재설치나 세이브 초기화를 하지 않습니다.
- 파일이 게임 업데이트 등으로 달라졌으면 자동 덮어쓰기를 중단합니다.
- 제거 후에도 검증된 원본 백업은 보존합니다.
- USB 분리 등으로 중단되면 다시 연결하고 런처에서 다시 실행해 주세요. 기록을 검사해 이어서 처리합니다.
- 중단된 작업이 남긴 임시 파일은 기록과 해시가 맞을 때만 정리하고, 불명확한 파일은 자동 삭제하지 않습니다.
- 예전 설치기 EXE로 설치했어도 런처가 같은 백업과 기록을 이어서 사용합니다.

### 백업 위치

- PC 백업·설치 기록·로그: `%LOCALAPPDATA%\ZECOLE\H3VR2\Quest\<기기ID>\200542`
- 기기 원본: `footlong.base.hdog.zecole-original-200542` (원래 게임 데이터 옆)

### 게임을 업데이트했다면

- 게임이 20261124C로 업데이트되면 게임 데이터가 새 원본으로 바뀌어 이전 한글패치(0.5.5 이하)가 사라집니다.
- 런처에서 **한글패치 설치**로 다시 설치하면 됩니다.

## 번역 범위와 제한

### 번역한 것

- 설정·메뉴·작업 안내
- 여러 표지/포스터와 ATM·경보 UI
- 초기 시스템 안내 자막 5종
- 포어미트 두 질문의 상황 요약
- 게임 시작 직후 포어미트 구출 장면(갇혔을 때·구출 직후)과 허브 상층 상황 보고 대사 자막 3개 (0.2.0부터)

### 영어로 남는 것

- Challenges/Sandboxes LED 전광판
- 일부 오류 코드
- 전체 NPC 음성 자막과 인사·작별 요약은 제공하지 않습니다.

### 자막에 대해

- 자막은 장면 진입·조작 시점에 맞춘 시간 표시이며, 실제 음성 재생을 추적하지 않습니다.
- 상황 요약은 실제 음성 시작/종료를 감지하는 자막이 아닙니다.
- 포어미트의 원래 랜덤 음성은 그대로 유지합니다.

전체 문구의 100% 번역이나 모든 게임 진행 경로의 검증을 보장하지 않습니다.
