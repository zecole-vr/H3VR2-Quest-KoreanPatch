# H3VR2 Quest 한국어 패치

제작자 **제콜 (ZECOLE)** · [YouTube](https://www.youtube.com/@zecole)

Hot Dogs, Horseshoes & Hand Grenades 2의 비공식 한국어 패치입니다.
원본 APK를 유지하고 외부 게임 데이터에 차분을 적용합니다.

> 최신 버전은 **0.5.1**입니다. [Releases](https://github.com/zecole-vr/H3VR2-Quest-KoreanPatch/releases/latest)에서 `H3VR2_Quest_Setup_v0.5.1.exe` 하나만 받으시면 됩니다. [검증 기록](maintenance/VALIDATION.md)에 완료·대기 항목을 구분합니다.

## 지원 환경

| 구분 | 지원 범위 |
|---|---|
| 게임 | Meta Quest 단독판 20261119E / versionCode 200534 |
| 지원 기기 | Quest 3, Quest 3S (실기 검증은 Quest 3) |
| 설치 도구 | Windows 10/11 x64, WebView2, .NET Framework 4.8 |
| 권장 여유 공간 | PC 작업 드라이브 7 GiB + 임시 드라이브 0.5 GiB / Quest 3 GiB |

APK·게임 데이터의 SHA256도 검사합니다. 다른 버전에는 설치하지 않습니다.
Quest 3S는 Quest 3과 같은 게임 파일을 쓰므로 설치를 허용합니다. Steam/PCVR, 휴대폰 단독 설치는 지원하지 않습니다.

## 설치

1. 정품 게임을 설치하고 한 번 실행한 뒤 완전히 종료합니다.
2. Quest 개발자 모드를 켜고 PC와 USB로 연결합니다.
3. 헤드셋에서 USB 디버깅을 허용합니다.
4. `H3VR2_Quest_Setup_v0.5.1.exe`의 **한글패치 설치**를 누릅니다.
5. **설치 완료** 후 게임을 실행합니다.

Python 등 실행 모듈은 EXE에 포함됩니다. ADB가 없으면 최초 한 번 약관 동의 후
Google 공식 Platform Tools 37.0.0을 받아 체크섬을 검증합니다.
첫 도구 다운로드·최신 버전 확인은 인터넷이 필요합니다.
최신 버전 확인 실패는 설치 상태와 별도로 표시하며 다시 시도할 수 있습니다.

## 제거·복구

게임 종료 후 같은 EXE의 **제거 · 원본 복구**를 누릅니다.
APK 재서명·재설치나 세이브 초기화를 하지 않습니다.
파일이 게임 업데이트 등으로 달라졌으면 자동 덮어쓰기를 중단합니다.

- PC 백업·설치 기록·로그: `%LOCALAPPDATA%\ZECOLE\H3VR2\Quest\<기기ID>\200534`
- 기기 원본: `footlong.base.hdog.zecole-original-200534` (원래 게임 데이터 옆)
- 제거 후에도 검증된 원본 백업은 보존합니다.
- USB 분리 등으로 중단되면 다시 실행하여 기록을 검사합니다. 중단된 작업이 남긴 임시 파일은 기록과 해시가 맞을 때만 정리하고, 불명확한 파일은 자동 삭제하지 않습니다.
- EXE를 옮기거나 다시 받아도 백업과 기록은 유지됩니다.

게임이 20261119E로 업데이트되면 게임 데이터가 새 원본으로 바뀌어 이전 한글패치(0.5.0 이하)가 사라집니다.
0.5.1 EXE의 **한글패치 설치**로 다시 설치하면 됩니다. 0.5.0 이하 EXE는 새 게임 버전에 설치하지 않습니다.

## 번역 범위와 제한

설정·메뉴·작업 안내·여러 표지/포스터와 ATM·경보 UI를 번역합니다.
Challenges/Sandboxes LED 전광판 및 일부 오류 코드는 영어로 유지합니다.
초기 시스템 안내 자막 5종과 포어미트 두 질문의 상황 요약을 포함합니다.
0.2.0부터 게임 시작 직후 포어미트 구출 장면(갇혔을 때·구출 직후)과 허브 상층 상황 보고 대사 자막 3개를 추가했습니다.
이 자막은 장면 진입·조작 시점에 맞춘 시간 표시이며 실제 음성 재생을 추적하지 않습니다.
포어미트의 원래 랜덤 음성은 유지합니다. 요약은 실제 음성 시작/종료를 감지하는 자막이 아닙니다.
전체 NPC 음성 자막과 인사·작별 요약은 제공하지 않습니다.
전체 문구의 100% 번역이나 모든 게임 진행 경로의 검증을 보장하지 않습니다.
